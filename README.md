# What is this?
These are the source files for a Beat Saber custom map made using the Vivify mod.

- [Map Download](https://beatsaver.com/maps/539c4)
- [Song](https://www.youtube.com/watch?v=xFX0mEnkNQ4)

# Why is it uploaded
So that others can learn from this map and hopefully fix something or improve in their own Vivify maps.

All assets except these models two were made by me, feel free to use them however.
[Badminton racket](https://sketchfab.com/3d-models/hyper-core8000-badminton-racket-3d-modeling-c6f5e27f657a48d6b3cbb52120d75f83)
[Shuttlecock](https://sketchfab.com/3d-models/shuttlecock-ec2087e9af244aaeb62b3c899174257d)
